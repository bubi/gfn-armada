# GFN Armada v0.1.0 PoC — experimental Linux ARM64 release

**Unmaintained, AI-generated Proof of Concept.** Project-specific code and patches
were created entirely by AI under human guidance; third-party code retains its
original authorship and licenses. No maintenance or support commitment, no upstream
endorsement, and not an official NVIDIA, AYN or ArmadaOS client.

This prerelease packages the **exact AppImage tested on the AYN Odin 2 Portal**
with ArmadaOS, including the patched Qualcomm Iris VA-API adapter. It keeps
NVIDIA's original web application, persistent login and controller support.

## Download and start

Download `gfn-armada-0.1.0-aarch64.AppImage` and `SHA256SUMS`. Keep the AppImage
at a stable path on the Odin. Run natively on **Linux ARM64**, without Proton:

```sh
sha256sum --ignore-missing -c SHA256SUMS
chmod +x gfn-armada-0.1.0-aarch64.AppImage
./gfn-armada-0.1.0-aarch64.AppImage --appimage-extract-and-run login
```

Add the AppImage as a **Non-Steam game**. Target: its absolute path; Start In:
its containing directory. Steam launch options:

```text
GFN_ARMADA_GAMESCOPE=nested GFN_ARMADA_BROWSER_IDENTITY=windows GFN_ARMADA_HEVC_EXPERIMENT=1 %command% --appimage-extract-and-run launch
```

`nested` provides Steam's tracked fullscreen Gamescope window; the Windows
browser identity and HEVC preference are experimental compatibility settings.
`%command%` is Steam's target substitution; extraction mode avoids requiring FUSE.
Alternatively, set `codec = "hevc"` in `~/.config/gfn-armada/config.toml` and omit
`GFN_ARMADA_HEVC_EXPERIMENT=1`. H.264 remains a fallback.

Set Steam Game Resolution to **1920×1080**, with the internal-display override
enabled. In GFN's original streaming settings choose **1920×1080 / 60 FPS** for
the verified setup. Steam's resolution does not configure NVIDIA's remote stream.
Confirm the active codec in stream statistics; the GFN codec selector may still
say Unsupported. [Detailed launch guide](../steam-client-launch.md).

## Verified scope and limitations

- Real H.264 and HEVC GFN sessions have correlated Chromium VA-API and Iris VPU
  frame evidence. The final Steam AppImage run reports H.265, VaapiVideoDecoder,
  1920×1080/60, 9,979 decoded frames and six browser drops; `/dev/video0` was open.
  No additional driver completion trace was captured in that final run.
- The user confirmed controller operation and correct borderless display from
  Steam. Steam overlay bindings, long-term focus/stability and suspend/reconnect
  behavior remain open.
- Output uses a GPU copy. No zero-copy, end-to-end latency or CPU/power-saving claim.
- AV1 has short-run VPU evidence but visible flicker; it remains experimental
  and is not enabled by these instructions.
- Catalog import and guarded Steam sync are implemented, but real account library
  import and generated per-game shortcuts have not been fully accepted. Unknown
  mappings fail; do not invent NVIDIA links. Sync writes require Steam stopped
  and make backups. Automatic startup sync/artwork remain open.
- Target tested: ArmadaOS `20261002.43c0cca`, kernel `7.2.6`, Snapdragon SM8550 /
  Adreno 740. No general compatibility claim for other systems.
